# Actividad Inicial - Módulo Desarrollo Web en Entorno Servidor

## Introducción
Esta actividad corresponde al segundo curso del módulo de Desarrollo de Aplicaciones Web en Entorno Servidor (2º DAW A) del IES Albarregas. El objetivo es desarrollar un proyecto de clase utilizando tecnologías web del lado del servidor.

## Descripción del Proyecto
La aplicación es una **aplicación web** desarrollada en el entorno **NetBeans** utilizando **Java**, **HTML** y **CSS**.
